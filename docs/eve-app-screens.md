# Eve Compass app screens

Captured on 20 November 2026 from the current Eve Compass app (branch `claude/product-name-compass`, commit `f6c5cf9`), on an iPhone 16e simulator (390 × 844 pt) with the status bar set to 9:41.

The app ran against the local test database and the local preview server (`school-backend/scripts/local-preview.ts`), with every outside service switched off. It was signed in with the demo teacher and demo parent accounts from `scripts/seed-demo.ts`. Every name, class and number on the screens is demo data, not a real student, parent or teacher. The school name is the one the demo school is set up with.

Saved as `public/images/eve-teacher-home.webp` and `public/images/eve-parent-home.webp`, each 520 × 1125. They replace the older public previews from evaradh.com (`cis-teacher-preview.png` and `cis-parent-preview.png`), which showed the app before it was renamed and restyled.

The case-study video (`public/media/eve-compass-demo.mp4`) was recorded earlier from the same demo school and already shows the Eve Compass name and design.
