# CIS Compass public app previews

Source: https://evaradh.com/#work, accessed 28 September 2026.

The teacher and parent phone screens are public HTML product previews on Evaradh. These are not authenticated app captures. Their class counts, attendance percentage and other values are illustrative interface data, not verified impact metrics.

Saved as `public/images/cis-teacher-preview.png` and `public/images/cis-parent-preview.png`, each 404 × 804. The existing preview DOM was isolated in the browser, doubled in display size and frozen on its first screen to avoid capturing a carousel transition. The original text, values, colors and phone UI were retained. No generated app imagery was used.

The shared CISAppScreens component supplies the homepage, school case study and all three design options. Captions identify the source and illustrative data. The old school website image is no longer rendered.
